=================================================================================
              Zapret2 Control Center v0.0.4 (Portable Edition, x64)
=================================================================================

Файл:    Zapret2-GUI-v0.0.4-portable.exe
Ядро:    bol-van/zapret v72.13 (winws.exe + WinDivert 2.2 x64)
Система: Windows 10 / 11 x64, нужен WebView2 Runtime

ЧТО ИСПРАВЛЕНО В v0.0.4
-----------------------

1. DISCORD: часть голосовых комнат подключалась «без звука»
   Причина: перехватывался только диапазон UDP 50000-65535. Discord выдаёт
   голосовые серверы ещё и на портах 19294-19344 — такие комнаты проходили мимо
   обхода, клиент показывал «Соединение установлено», а голос не шёл ни в одну,
   ни в другую сторону.
   Что сделано: диапазон 19294-19344 добавлен и в фильтр захвата WinDivert
   (--wf-udp), и в профиль Discord. Добавлен отдельный профиль для медиасерверов
   discord.media на альтернативных TCP-портах Cloudflare (2053, 2083, 2087,
   2096, 8443) — раньше обрабатывался только 443.

2. TELEGRAM: сообщения грузились, медиафайлы — нет
   Причина: серверы Telegram работают по MTProto, который вообще не передаёт имя
   хоста. Фильтрация по доменам для них не работает в принципе, поэтому трафик
   к дата-центрам Telegram не попадал ни в один профиль и оставался
   заблокированным.
   Что сделано: добавлен список подсетей ipset-telegram.txt (официальный
   core.telegram.org/resources/cidr.txt) и профиль, отбирающий трафик по IP
   с --dpi-desync-any-protocol и ограничением --dpi-desync-cutoff=n3.

3. СТРАТЕГИЯ: заменена на multisplit + seqovl с TLS-паттерном
   Прежняя fake,multidisorder заменена на схему из проекта
   Flowseal/zapret-discord-youtube (multisplit, split-pos=1, split-seqovl
   с паттерном ClientHello), которая устойчивее работает у российских
   провайдеров. Для YouTube/Google добавлен --ip-id=zero.

4. СПИСКИ ДОМЕНОВ значительно расширены
   list-general.txt  — Discord (все домены), Cloudflare/ECH, DoH-резолверы,
                       Telegram (веб), стриминг, прочее
   list-google.txt   — YouTube и Google (отдельная стратегия)
   list-exclude.txt  — исключения: банки, Яндекс, Steam, Twitch и др.,
                       чтобы обход не ломал российские сервисы
   ipset-telegram.txt — подсети дата-центров Telegram

5. ПРЕСЕТ ТЕПЕРЬ ОДИН
   «Универсальный (YouTube + Discord + Сайты)». Остальные убраны, чтобы не
   путаться. Настройка — через быстрые переключатели на главном экране.

6. АВТОМАТИЧЕСКОЕ ЛОГИРОВАНИЕ В ФАЙЛ
   Весь вывод ядра (winws запускается с --debug) и события приложения пишутся в
   %LOCALAPPDATA%\\Zapret2-GUI\\logs\\zapret2.log
   При достижении 10 МБ файл упаковывается в zip с меткой времени, хранятся
   последние 5 архивов. В окне логов и в меню трея есть кнопка «Папка логов».
   В интерфейс выводится не весь поток (иначе окно захлёбывается), в файл —
   всё целиком.

7. ХОСТЛИСТЫ: заработали импорт и экспорт
   Кнопки открывают системные диалоги выбора файла. Добавленные вами домены
   записываются в list-user.txt и list-exclude-user.txt перед запуском ядра —
   раньше вкладка была чисто декоративной и ни на что не влияла.

8. ИСПРАВЛЕНИЯ ИНТЕРФЕЙСА
   - Счётчики у пунктов «Пресеты» и «Хостлисты» брались из зашитых чисел
     (5 и 12) и не менялись. Теперь считаются по факту, у пустого списка
     значка нет.
   - На вкладке «Пресеты» карточки параметров показывали значения по
     умолчанию (multisplit / none / 2 / d3 / TCP 443), не имеющие отношения
     к реальной конфигурации, а их правка ни на что не влияла. Для пресета
     со стратегией теперь выводится разбор настоящих профилей ядра.
     Редактируемые поля остались у пресетов, созданных вручную.
   - Плашка обновления и кнопка в настройках показывали несуществующую
     версию ядра «v69.2»; текст про автораспаковку релиза с GitHub не
     соответствовал действительности.
   - В настройках убраны неработающие переключатели: установка службы
     Windows, автозапуск и «автовыгрузка при закрытии» ничего не делали,
     а счётчик зависших процессов всегда показывал ноль.
   - Утверждение «Portable .exe весит всего ~971 КБ» заменено фактическим
     размером и составом сборки.
   - Состояние «Ошибка» в боковой панели отображалось как «Выключен».
   - В заголовке окна логотип рисовался дважды (картинка поверх иконки),
     а двойной клик по заголовку срабатывал два раза и окно не разворачивалось.
   - Колонка «Перехватов» в хостлистах всегда показывала прочерк — заменена
     на дату добавления.
   - Тема оформления и поведение крестика не сохранялись между запусками.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
- Откройте «Логи» → «Папка логов» и посмотрите zapret2.log. Там видно, какие
  профили загрузились, сколько доменов прочитано из каждого списка и как ядро
  обрабатывает конкретные соединения.
- Переключатели на главном экране позволяют отключить отдельные профили
  (QUIC, Discord, Telegram) — так проще понять, какой из них мешает.
- «Весь трафик (All)» снимает фильтрацию по спискам доменов; исключения
  (банки, Яндекс) при этом продолжают действовать.

Проверить, что ядро принимает строку запуска, можно из исходников:
  powershell -ExecutionPolicy Bypass -File scripts\\verify_args.ps1
