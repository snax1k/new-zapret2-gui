=================================================================================
              Zapret2 Control Center v0.0.5 (Portable Edition, x64)
=================================================================================

Файл:    Zapret2-GUI-v0.0.5-portable.exe
Ядро:    bol-van/zapret v72.13 (winws.exe + WinDivert 2.2 x64)
Система: Windows 10 / 11 x64, нужен WebView2 Runtime

Версия организационная: логика обхода не менялась, стратегия и списки доменов
те же, что в v0.0.4. Изменились раскладка файлов и работа с пресетами.

ЧТО ИЗМЕНИЛОСЬ В v0.0.5
-----------------------

1. СПИСКИ ВЫНЕСЕНЫ ИЗ КАТАЛОГА ЯДРА

   Было:                          Стало:
   %LOCALAPPDATA%\Zapret2-GUI\    %LOCALAPPDATA%\Zapret2-GUI\
   ├─ bin\                        ├─ bin\        (ядро, перезаписывается)
   │   ├─ winws.exe               │   ├─ winws.exe
   │   ├─ WinDivert*              │   ├─ WinDivert*
   │   ├─ *.bin                   │   └─ *.bin
   │   ├─ list-general.txt        ├─ host-list\  (списки)
   │   ├─ list-google.txt         │   ├─ list-general.txt
   │   ├─ list-exclude.txt        │   ├─ list-google.txt
   │   ├─ ipset-telegram.txt      │   ├─ list-exclude.txt
   │   ├─ list-user.txt      ←!   │   ├─ ipset-telegram.txt
   │   └─ list-exclude-user.txt   │   ├─ list-user.txt        ← ваше
   ├─ dist\                       │   └─ list-exclude-user.txt ← ваше
   ├─ logs\                       ├─ dist\
   └─ WebViewData\                ├─ logs\
                                  └─ WebViewData\

   Дело не только в порядке. Каталог bin\ распаковывается из ресурсов exe при
   КАЖДОМ запуске, целиком. Пользовательские списки лежали ровно там, то есть
   затирались при старте — их спасало только то, что источником правды был
   localStorage и файл заново создавался перед запуском ядра. Теперь bin\
   содержит только заменяемое, host-list\ — только данные.

   Файлы list-user.txt и list-exclude-user.txt в поставку не входят вообще,
   поэтому распаковка их не трогает. Если они отсутствуют, приложение создаёт
   пустые: ядро завершается при старте, если любой указанный --hostlist
   не читается.

   При первом запуске v0.0.5 существующие list-user.txt и list-exclude-user.txt
   автоматически переносятся из bin\ в host-list\.

   В командной строке winws пути стали относительными от каталога ядра:
   --hostlist=../host-list/list-general.txt

2. ЭКСПОРТ И ИМПОРТ ПРЕСЕТОВ

   На вкладке «Пресеты» появились кнопки «Экспорт» и «Импорт».

   Экспорт сохраняет все пресеты в .json:
     { "app": "zapret2", "kind": "presets", "version": 1, "presets": [ ... ] }

   Импорт добавляет пресеты из файла к существующим, ничего не удаляя.
   Некорректные записи пропускаются (нужны непустое имя и args с rawArgs
   или desyncMode); при совпадении идентификатора импортированному пресету
   выдаётся новый, чтобы не затереть текущий. Принимаются как файлы формата
   выше, так и просто массив пресетов.

   Зачем: пресеты хранятся в localStorage интерфейса, а не в файлах, и при
   обновлении версии хранилища сбрасываются. Экспорт — способ их не потерять,
   перенести на другой компьютер или откатиться к рабочей конфигурации.

3. ВНИМАНИЕ: ПРЕСЕТЫ СБРАСЫВАЮТСЯ ПРИ ЭТОМ ОБНОВЛЕНИИ

   Ключ хранилища пресетов поднят с v5 на v6, потому что сохранённый пресет
   версии 0.0.4 ссылается на списки по старым путям (list-general.txt вместо
   ../host-list/list-general.txt) и после обновления ядро не смогло бы их
   прочитать.

   Хостлисты, быстрые переключатели и тема оформления НЕ сбрасываются.

   Если вы успели создать свои пресеты в 0.0.4 — сначала запустите старую
   версию и выгрузите их... впрочем, в 0.0.4 экспорта ещё не было. Начиная
   с этой версии такие обновления можно переживать без потерь.

4. МЕЛОЧИ

   - Кнопку удаления получают все пресеты, кроме поставляемых со сборкой
     (раньше проверялся префикс имени, и импортированные удалить было нельзя).
   - В подсказках формы создания пресета показаны новые пути к спискам.

ГДЕ ЧТО ЛЕЖИТ
-------------
%LOCALAPPDATA%\Zapret2-GUI\bin\        ядро zapret, перезаписывается при запуске
%LOCALAPPDATA%\Zapret2-GUI\host-list\  списки доменов и подсетей
%LOCALAPPDATA%\Zapret2-GUI\logs\       журналы, ротация 10 МБ, 5 архивов
%LOCALAPPDATA%\Zapret2-GUI\WebViewData\ пресеты, настройки, хостлисты интерфейса

Проверить, что ядро принимает строку запуска (в том числе новые пути к спискам):
  powershell -ExecutionPolicy Bypass -File scripts\verify_args.ps1
