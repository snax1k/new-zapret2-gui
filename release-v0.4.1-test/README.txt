=================================================================================
         Zapret2 Control Center v0.4.1-test (Portable Edition, x64)
=================================================================================

Файл:    Zapret2-GUI-v0.4.1-test-portable.exe
Ядро:    bol-van/zapret v72.13 (winws.exe + WinDivert 2.2 x64)

ТЕСТОВАЯ СБОРКА. Не для всех: нужна, чтобы проверить новый подбор на
настоящих провайдерах. Если что-то пошло не так — пришлите журнал подбора
из папки логов.

ЧТО НОВОГО
----------
  1. Библиотека из 20 способов обхода вместо 7. Все собраны из режимов,
     которые описаны в документации ядра. Самые частые победители стоят
     первыми.

  2. Подбор в два этапа. Сначала быстрый отсев — по одной попытке на
     каждую цель: неподходящий способ отбрасывается за несколько секунд.
     Первые четыре прошедших проверяются полностью, по три попытки. Если
     ни один из них не выдержал, отсев продолжается дальше по списку.

  3. Сборка пресета целиком. В окне подбора — вкладка «Весь пресет»:
     программа подбирает способ для сайтов и Discord, затем для YouTube,
     а потом проверяет оба вместе на всех пяти целях сразу. В конце —
     сводка и кнопка «Применить»; применённое отменяется одной кнопкой
     «Вернуть как было». Само ничего не меняется.

  4. Смена адреса цели. Если цель не открылась ни при одном способе,
     подбор берёт её следующий адрес из DNS и повторяет перебор: бывает,
     что режется сам адрес, а не соединение.

ЧТО НЕ ПРОВЕРЯЕТСЯ
------------------
QUIC и голос Discord подбором не проверяются — честной пробы для них нет.
Эти профили остаются как были.

ОБНОВЛЕНИЯ
----------
Тестовая сборка считается младше выпуска 0.4.1: когда он выйдет, программа
предложит обновиться.
