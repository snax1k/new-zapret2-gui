              Zapret2 Control Center v0.2.0 (Portable Edition, x64)
=================================================================================

Файл:    Zapret2-GUI-v0.2.0-portable.exe
Ядро:    bol-van/zapret v72.13 (winws.exe + WinDivert 2.2 x64)

Появилась очистка кэша Discord. Больше в этом выпуске ничего не менялось:
профили обхода, стратегии и все настройки прежние.

ОЧИСТКА КЭША DISCORD
--------------------
Настройки -> "Кэш Discord".

Зачем. Обход рвёт соединения посреди загрузки, Discord складывает в кэш
обрезанные ответы и продолжает показывать поломку уже после того, как связь
починили. Помогает, когда Discord висит на "Starting" или не грузит картинки
при работающем обходе.

Кнопка "Посчитать" показывает, сколько занимает кэш каждой установленной
сборки Discord. Сама по себе она ничего не удаляет.

Что удаляется:  Cache, Code Cache, GPUCache, Dawn*Cache, Service Worker, logs.

Что НЕ трогается:

  * Local Storage — там ваш вход в аккаунт. Разлогинить вас очистка не может,
    это заложено в программу, а не оставлено на удачу.
  * %LOCALAPPDATA%\Discord — сам клиент, его модули и обновлялка. Цена ошибки
    здесь переустановка с нуля, поэтому каталог не трогается вовсе.
  * Настройки Discord, горячие клавиши, список серверов.

Удаление необратимо, поэтому:

  * размер показывается ДО удаления — и считается только по тем каталогам,
    которые действительно будут удалены, а не по всей папке Discord;
  * кнопка срабатывает со второго нажатия: первое показывает, сколько именно
    будет удалено;
  * каждый удалённый путь пишется в журнал.

Пока Discord запущен, его файлы заблокированы, и очистить кэш нельзя. Поэтому
кнопка называется "Закрыть Discord и очистить" — программа закроет его сама,
но только по вашему нажатию. Идущий звонок при этом оборвётся.

Поддерживаются Discord, Discord PTB, Discord Canary и Discord Development —
показываются только те, что действительно установлены.

КНОПКА "ОЧИСТИТЬ ЗАВИСШИЕ WINWS" ТЕПЕРЬ ОТЧИТЫВАЕТСЯ ЧЕСТНО
---------------------------------------------------------
Раньше она писала в журнал "Все зависшие процессы очищены (taskkill /F /IM
winws.exe выполнено)" через фиксированные 0,8 секунды — не выполнив taskkill
и не проверив результат.

Теперь программа ищет посторонние процессы winws.exe (свой не трогает, для
него есть кнопка питания), снимает их, проверяет, что они действительно
завершились, и пишет в журнал числа: сколько нашли и сколько сняли. Если
процесс не снялся, так и будет написано, а подробности по каждому попадут
в zapret2.log.

ЕСЛИ DISCORD ВИСИТ НА "STARTING"
--------------------------------
Порядок прежний, очистка кэша добавляется последним шагом:

  1. Включите обход.
  2. Проверьте плашку помех на главном экране: системный прокси и VPN
     перекрывают обход, и это самая частая причина.
  3. Откройте "Пресеты" -> "Стратегия сайтов и Discord" ->
     "Подобрать автоматически", примените вариант, который прошёл.
  4. Полностью закройте и заново запустите Discord.
  5. Если не помогло — Настройки -> "Кэш Discord" -> очистить, затем снова
     запустить Discord.

Если и это не помогло, пришлите журнал:
%LOCALAPPDATA%\Zapret2-GUI\logs\zapret2.log

АНТИВИРУС
---------
Сборка не подписана сертификатом, поэтому антивирусы периодически помечают
её эвристикой машинного обучения. Это ложное срабатывание.

Сумма этой версии лежит в SHA256SUMS.txt рядом со сборкой. Проверить:

  Get-FileHash .\Zapret2-GUI-v0.2.0-portable.exe -Algorithm SHA256

ЧТО НЕ ИЗМЕНИЛОСЬ
-----------------
Профили QUIC, голоса и медиасерверов Discord, YouTube/Google и обычных
сайтов. Обе группы автоподбора, счётчик активности, проверка окружения,
сброс кэша DNS при включении обхода, автопроверка обновлений, оформление.
Пресеты, хостлисты и настройки не сбрасываются.

Обновить ядро zapret приложение по-прежнему не умеет: winws.exe и WinDivert
вшиты в exe ресурсами и приезжают только с новой сборкой.
