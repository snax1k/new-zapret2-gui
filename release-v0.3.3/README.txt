=================================================================================
              Zapret2 Control Center v0.3.3 (Portable Edition, x64)
=================================================================================

Файл:    Zapret2-GUI-v0.3.3-portable.exe
Ядро:    bol-van/zapret v72.13 (winws.exe + WinDivert 2.2 x64)

Автоподбор перестал врать. Для Discord он впервые находит рабочую стратегию.

ПОЧЕМУ ПОДБОР НЕ НАХОДИЛ НИЧЕГО
-------------------------------
Проверочное соединение подбора стучалось к Discord по устаревшему TLS 1.0.
Так .NET ведёт себя по умолчанию в программах, собранных без указания
версии среды. Discord такие соединения не принимает.

Выходило так: рабочая стратегия проводила запрос мимо DPI, сервер Discord
отказывал из-за версии TLS, и подбор записывал её в провалы. Для Discord
подбор не мог найти ничего ни в одной прошлой версии. Google TLS 1.0 пока
принимает, поэтому по YouTube результаты могли быть верными.

На машине разработчика после исправления: multidisorder — 9 из 9 проб,
остальные шесть вариантов — честные 0 из 9.

Тот же дефект сидел в двух местах, исправлены оба:
  * вкладка «Диагностика» — её проверка Discord тоже врала;
  * обновление списка запасных узлов для прокси Telegram — список не
    обновился ни разу, мост работал на встроенном.

ПРОВЕРКА КАК У НАСТОЯЩЕГО DISCORD
---------------------------------
Подбор теперь отправляет не своё приветствие TLS, а записанное с браузера
Edge — клиент Discord сделан на том же движке. Оно весит около 1,7 КБ и не
помещается в один пакет, как и у настоящего клиента. DPI обращается с такими
приветствиями иначе, чем с короткими, поэтому стратегия, прошедшая подбор,
теперь проверена в тех же условиях, в которых будет работать Discord.

ПОДБОР В ТРИ РАЗА БЫСТРЕЕ
-------------------------
Если хотя бы одна цель не открылась ни разу, вариант дальше не проверяется:
Discord нужны все цели сразу. Было почти пять минут, стало около полутора.

ОТЧЁТ ПОДБОРА
-------------
Каждый прогон пишет подробный отчёт в папку логов: autotune-<дата>.txt.
По каждой проверке видно, дошла ли она до ядра, обработало ли ядро
соединение и вмешивался ли DPI. Если подбор покажет что-то странное —
присылайте этот файл, он маленький и хранится отдельно от общего журнала.

Подбор больше не проверяет стратегии сайтов в режиме «Весь трафик»: в этом
режиме весь HTTPS идёт по стратегии YouTube, и перебор мерил бы одно и то же.
Если режим включён, программа предупредит.

ПРОКСИ TELEGRAM НАДЁЖНЕЕ
------------------------
Запасные узлы часто отвечают «сервис недоступен» и через секунду снова
работают. Раньше мост пробовал три узла и сдавался, теперь перебирает их до
восьми секунд. Если узлы не ответили, а прямые адреса Telegram закрыты, мост
сразу отдаёт клиенту отказ, и Telegram переподключается, а не ждёт
лишних десять секунд. На 40 проверочных соединениях — 40 успешных.

АНТИВИРУС
---------
Сборка не подписана сертификатом, поэтому антивирусы периодически помечают
её эвристикой машинного обучения. Это ложное срабатывание.

Сумма этой версии лежит в SHA256SUMS.txt рядом со сборкой. Проверить:

  Get-FileHash .\Zapret2-GUI-v0.3.3-portable.exe -Algorithm SHA256
