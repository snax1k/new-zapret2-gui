=================================================================================
              Zapret2 Control Center v0.0.3 (Portable Edition, x64)
=================================================================================

Файл:   Zapret2-GUI-v0.0.3-portable.exe
Ядро:   bol-van/zapret v72.13 (winws.exe + WinDivert 2.2 x64)
Система: Windows 10 / 11 x64, требуется WebView2 Runtime (входит в Windows 11,
         в Windows 10 обычно устанавливается вместе с Microsoft Edge)

ЗАПУСК
------
Запустите exe. Windows запросит права администратора — они обязательны:
без них драйвер WinDivert не сможет перехватывать пакеты.

Всё содержимое (интерфейс, winws.exe, WinDivert, списки доменов и TLS-пейлоады)
распаковывается в %LOCALAPPDATA%\Zapret2-GUI. Открыть эту папку можно из меню
в трее.

ЧТО ИСПРАВЛЕНО В v0.0.3
-----------------------
1. Главная причина неработоспособности v0.0.2: в строку запуска winws.exe
   не попадали параметры --wf-tcp / --wf-udp. Без них ядро завершалось сразу
   с ошибкой «windivert filter : must specify port or/and partial raw filter»,
   и обход не работал вообще, хотя интерфейс показывал «Подключено».

2. Пресеты содержали параметр --dpi-desync-autottl=auto:2:3-12. Ядро принимает
   только формат [+|-]<delta>[:<min>[-<max>]], а на «auto:» завершается с кодом 1.
   Значение исправлено и теперь проверяется перед запуском.

3. Интерфейс сообщал «Подключено» независимо от того, запустилось ядро или нет.
   Теперь состояние определяется по реальному процессу winws.exe, а его вывод
   (включая текст ошибки) попадает во вкладку «Логи».

4. Стратегии заменены на рабочие конфигурации zapret v72 для Windows: отдельные
   профили для QUIC (UDP 443), голоса Discord (UDP 50000-65535, l7 discord/stun),
   HTTP (TCP 80) и HTTPS (TCP 443) с фильтрацией по списку доменов.

5. Быстрые переключатели на главном экране теперь действительно меняют строку
   запуска, а не только подсвечиваются.

6. Диагностика больше не подставляет заранее заданные «успешные» результаты —
   показывается фактический итог DNS, TCP и двух TLS-рукопожатий.

7. Проверка обновлений обращается к GitHub API bol-van/zapret и показывает
   настоящую версию вместо имитации загрузки.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
- Откройте вкладку «Логи»: там видна точная строка запуска winws.exe и его вывод.
- Включите переключатель «Подробный лог» (winws запускается с --debug).
- Попробуйте пресет «Мягкий режим (multisplit)» — он не использует поддельные
  пакеты и реже конфликтует с антивирусами и корпоративными сетями.
- Если в логах есть упоминание драйвера WinDivert, приложение само попробует
  удалить зависшую службу; после этого нажмите «Включить» ещё раз.
- Стратегия обхода зависит от провайдера. Единственного универсального набора
  параметров не существует — перебирайте пресеты.

Проверить, что ядро принимает строку запуска, можно скриптом из исходников:
  powershell -ExecutionPolicy Bypass -File scripts\verify_args.ps1
(он разбирает аргументы через --wf-save и не трогает драйвер)
