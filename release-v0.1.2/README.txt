=================================================================================
              Zapret2 Control Center v0.1.2 (Portable Edition, x64)
=================================================================================

Файл:    Zapret2-GUI-v0.1.2-portable.exe
Ядро:    bol-van/zapret v72.13 (winws.exe + WinDivert 2.2 x64)

Репозиторий стал публичным, и приложение научилось обновляться само.
Стратегия обхода не менялась.

ПРОВЕРКА И УСТАНОВКА ОБНОВЛЕНИЙ
-------------------------------
Приложение сравнивает свою версию с тегом последнего релиза в
github.com/snax1k/new-zapret2-gui и, если вышла новее, предлагает поставить.

Последовательность установки:

  1. Скачивание сборки из ассетов релиза (с прогрессом).
  2. Сверка SHA-256 с файлом SHA256SUMS.txt из того же релиза.
  3. Запуск вспомогательного .cmd: он ждёт выхода текущего процесса по PID,
     подменяет exe и стартует новую версию.

Запущенный exe нельзя перезаписать самому себе — отсюда третий шаг.
Приложение работает от администратора, порождённый процесс наследует права.

ЧТО СДЕЛАНО ДЛЯ БЕЗОПАСНОСТИ
----------------------------
  * Установка выполняется ТОЛЬКО при наличии SHA256SUMS.txt в релизе. Нет
    контрольной суммы — кнопка установки не показывается, предлагается
    скачать вручную. Иначе мы запускали бы непроверенный exe с правами
    администратора.
  * При расхождении суммы файл удаляется, установка отменяется, в лог идёт
    и ожидаемое, и полученное значение.
  * Ссылка на загрузку проверяется: принимаются только адреса на github.com
    и githubusercontent.com. Адрес приходит из интерфейса, и без проверки
    подменённая страница могла бы подсунуть чужой файл.
  * Перед выходом снимается ядро winws, чтобы не осталось процесса с
    загруженным драйвером.

ВЕРСИЯ ТЕПЕРЬ ПРОВЕРЯЕТСЯ ПРИ СБОРКЕ
------------------------------------
Версия живёт в трёх местах: build.ps1, AppVersion в NativeApp.cs и
APP_VERSION в AppContext.tsx. Если они разойдутся, проверка обновлений начнёт
врать — предлагать уже установленное либо молчать о вышедшем. Сборка теперь
падает с понятным сообщением, если значения не совпали.

Заодно build.ps1 кладёт SHA256SUMS.txt рядом со сборкой, а publish_release.ps1
сверяет его перед публикацией.

ПУБЛИКАЦИЯ РЕЛИЗА (для автора)
------------------------------
  $env:GITHUB_TOKEN = "ваш_токен"
  powershell -ExecutionPolicy Bypass -File scripts\publish_release.ps1

Скрипт создаёт тег и релиз, заливает exe и SHA256SUMS.txt, описание берёт из
этого README.txt. Токен читается из переменной окружения, в репозиторий не
попадает и стирается при закрытии окна PowerShell.

ЧТО НЕ ИЗМЕНИЛОСЬ
-----------------
Шесть профилей, списки, автоподбор стратегии, счётчик активности, проверка
окружения — как в v0.1.1. Пресеты, хостлисты и настройки не сбрасываются.

Обновить ядро zapret приложение по-прежнему не умеет: winws.exe и WinDivert
вшиты в exe ресурсами и приезжают только с новой сборкой. Выход новой версии
ядра теперь отмечается отдельной строкой в логе.
