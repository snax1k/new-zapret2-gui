=================================================================================
                 Zapret2 Control Center GUI v0.0.2 (Portable Edition)
=================================================================================

Архитектура: Single-file Portable Executable (Windows 10 / Windows 11 x64)
Интеграция: bol-van/zapret (winws.exe, WinDivert 64-bit)

🚀 ОСОБЕННОСТИ И ПРЕИМУЩЕСТВА СБОРКИ v0.0.2:
- Полностью автономный единый .exe файл (не требует распаковки или внешних папок).
- Автоматический запрос прав Администратора (UAC Elevation) при запуске.
- Встроенный Watchdog: автоматическое обнаружение и завершение зависших процессов
  winws.exe и выгрузка службы WinDivert при старте и выходе.
- Автообновление ядра: скачивание и распаковка новых релизов с GitHub bol-van/zapret.
- Системный трей Windows с контекстным меню и иконкой Zapret2.
- Настройка поведения при закрытии: Сворачивать в трей (по умолчанию) или Закрыть полностью.
- Светлая и Тёмная темы оформления (Windows 11 Fluent).
- Ступенчатый GoodCheck DPI-тест с контрольным шагом проверки TLS.
- Редактор пресетов с подробными подсказками и примерами флагов.

ЗАПУСК:
Просто запустите "Zapret2-GUI-v0.0.2-portable.exe".
