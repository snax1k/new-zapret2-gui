# Руководство пользователя

`guide.html` — исходник, `Zapret2-rukovodstvo-v0.1.5.pdf` — собранный из него PDF
(21 страница), `img/` — снимки экранов.

## Как пересобрать PDF

Печатает headless Edge, отдельный инструмент не нужен. Кириллица и вёрстка
берутся из системных шрифтов, поэтому ничего доустанавливать не надо.

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" `
  --headless=new --disable-gpu --no-pdf-header-footer `
  --print-to-pdf="docs\user-guide\Zapret2-rukovodstvo-v0.1.5.pdf" `
  --virtual-time-budget=15000 `
  "docs\user-guide\guide.html"
```

Пути должны быть абсолютными и в кавычках: без кавычек Edge принимает часть
пути с пробелом за вторую вкладку и отвечает `Multiple targets are not supported`.

## Как переснять экраны

Снимки сделаны с интерфейса, запущенного на dev-сервере (`npm run dev`,
порт 1420), через временную страницу-обёртку в `public/`. Обёртка грузила
приложение в iframe того же origin, нажимала кнопки по тексту и **отключала
CSS-анимации** — иначе снимок ловит середину перехода и подсветка в боковом
меню выглядит застрявшей между разделами.

Три кадра сняты с настоящего окна программы, потому что в браузере их получить
нельзя: обход включён (`02-glavnaya-vkl`), список найденных помех
(`03-pomehi`) и живой журнал ядра (`09-logi`). Без нативной части ядро не
запускается, и этих состояний в браузере не существует.

Окно программы снимается только копией области экрана: `PrintWindow` отдаёт для
WebView2 пустой прямоугольник. Нажимать в окне внешними средствами нельзя —
программа работает от администратора, и Windows запрещает слать ей ввод из
процесса с обычными правами.

## Что проверить перед выпуском новой версии

Снимки устаревают быстрее текста. При смене версии:

* номер версии на титуле и в имени PDF;
* снимки тех экранов, которые менялись;
* раздел «Пресеты и стратегии» — он описывает две группы автоподбора,
  появившиеся в 0.1.5.
